# TOEFL House — CRM / Workspace / Communication

**STATUS: CURRENT CANONICAL — NORMATIVE**

## CRM

CRM manages visitor/lead/follow-up/conversion interaction history without becoming student, academic or financial authority.

Automation rules are configuration, not a grant of CRM record authority. When
a rule schedules a follow-up, the canonical follow-up command re-authorizes
the triggering actor and configured assignee against the visitor's immutable
origin branch in the same transaction; an unscoped rule never turns a
branch-scoped follow-up capability into global authority.

## Employee Workspace

Workspace is:

- work-first
- exception-first
- effective-identity aware
- lifecycle/scope aware
- role-aware but not role-locked
- projection/composition only

Workspace actions must invoke canonical command/query authorities and be re-authorized at command time.

## Work Management

Tasks/work items coordinate work and queues without becoming business-state authority.

## Communication

Notifications are projections about communication, not domain events themselves. Recipient/read state does not redefine the underlying domain fact.

## Target gaps

SLA timers, automatic queue assignment, escalation/adapters, richer notification preferences/channels, and some inbox/reminder breadth remain target work where explicitly deferred.
