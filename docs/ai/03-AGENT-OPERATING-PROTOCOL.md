# Agent Operating Protocol

**STATUS: CURRENT CANONICAL — MANDATORY**

Every engineering task follows:

`READ → UNDERSTAND → CLASSIFY → PLAN → CHANGE → VERIFY → REVIEW → DOCUMENT → REPORT`

## Read
Load canonical governance and relevant implementation/test evidence before editing.

## Understand
Identify authority, lifecycle, scope, invariants, dependencies and failure modes.

## Classify
Classify the task as bug fix, invariant hardening, implementation completion, governed architecture change, target-state extension, deferred work, or future enhancement.

## Verify
Run the strongest applicable evidence level. Do not report a stronger level than was actually executed.

## Report
State files changed, tests run, results, limitations, documentation changes and remaining uncertainty.
