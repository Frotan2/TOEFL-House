# Task Execution Lifecycle

**STATUS: CURRENT CANONICAL — NORMATIVE**

For material work, use the following gates:

1. **Discovery** — establish actual implementation.
2. **Impact analysis** — map affected domains/contracts.
3. **Authority check** — identify the owning fact and writer.
4. **Design** — choose the smallest correct solution.
5. **Implementation** — change only what is justified.
6. **Invariant check** — review DB/business/security invariants.
7. **Test** — run relevant tests.
8. **Regression** — verify adjacent paths.
9. **Documentation** — update canonical knowledge when behavior/rules changed.
10. **Certification** — only make claims supported by evidence.
